                How to read this

                • Exploited: on CISA's Known Exploited Vulnerabilities list, so attackers are using it. Patch these first.
                • CVSS: how severe it is, 0–10 (9+ critical, 7+ high). "vendor score" means NVD hasn't analysed it yet, so the score is the vendor's own.
                • CISA: PoC / Exploited / None: CISA's early assessment of a new CVE. "PoC" means public exploit code exists.
                • EPSS: estimated chance it will be exploited in the next 30 days.
                • CISA deadline: the patch deadline for U.S. federal agencies, a useful benchmark.
                • Ransomware: known to be used in ransomware attacks.

                      About these sources

                      • Ransomware leak sites (ransomware.live): organisations a gang claims to have attacked. Usually days before the news; occasionally a false claim.
                      • HHS breach reports: breaches of health information affecting 500+ people. HHS publishes them about 4–6 weeks after they're reported.
                      • CISA device advisories: security flaws in medical devices and clinical software.
                      • FDA: Class I recalls (most serious) and MedWatch safety alerts.
